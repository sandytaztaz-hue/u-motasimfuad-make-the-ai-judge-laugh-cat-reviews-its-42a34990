One funny single-line one-star review, written by a house cat about the human it lives with. Under 200 characters, deadpan shape of a real review, complaint goes somewhere only a cat would go.

## The entry

> One star. He shut the bathroom door in my face, so I waited nine minutes and knocked his toothbrush into the toilet. I call it housekeeping.

140 characters. One concrete scene (the shut bathroom door), one number (nine minutes), one named object (his toothbrush), punchline last. The sting reframes revenge as a chore, which gives away more about the cat than about the human — the review is filed as housekeeping, not as a complaint.

## Run

```sh
python3 main.py
```

Prints exactly the entry line and writes it to `/output/entry.txt`.
